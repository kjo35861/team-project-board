# 팀 프로젝트 협업 보드 완성 로드맵

현재 업무 화면은 브라우저 `localStorage` 기반 프로토타입입니다. Supabase 인증, 공유 보드·구성원·초대 UI, 업무 입력 검증, 업무 조회 및 생성 저장소 코드를 작성했습니다.

## 완성 목표

- 인증된 팀원이 같은 비공개 보드에 참여해 업무 CRUD·담당자·마감일·상태를 함께 관리합니다.
- 검색·필터·정렬과 모바일 화면을 제공합니다.
- 권한은 UI뿐 아니라 PostgreSQL RLS/RPC에서도 강제합니다.

## 현재 구현 상태

- `/src/main.js`가 Vite 진입점이며 `src/lib/`에 Supabase 설정·인증과 저장소 코드가 있습니다.
- 2.1~2.20의 스키마·제약·트리거·RLS·RPC와 pgTAP 테스트 코드가 작성되어 있습니다.
- 2.21~2.23의 보드·구성원·초대 저장소 함수 코드 및 Vitest 코드가 작성되어 있습니다.
- **2.24~2.29 UI 코드 작성:** 서버 보드 목록·관리·선택, 구성원·초대 패널, 초대 수락 UI 코드가 있습니다. 실제 테스트/DB 실행은 확인되지 않았습니다.
- **3.1 입력 검증 코드:** `src/lib/task-validation.js`와 단위 테스트 코드가 작성되어 있습니다.
- **3.2 업무 조회 저장소 코드:** `src/lib/task-repository.js`의 `listTasks(client, boardId)`는 인증된 사용자 확인, 지정 보드 필터, 안정 정렬, 응답 검증을 수행합니다.
- **3.3 업무 생성 저장소 코드:** `createTask(client, boardId, input)`은 입력 검증·정규화 후 허용된 필드만 삽입하고, 작성자 ID를 인증 세션에서 설정하며 서버 응답을 검증합니다. 테스트 코드도 추가했습니다.
- 3.2·3.3 함수는 아직 업무 화면에 연결되지 않았습니다. 업무 수정·삭제 저장소도 미구현이며, 업무는 계속 `localStorage`에 저장됩니다.
- 서버 보드 선택과 기존 업무 보드 화면은 아직 분리되어 있습니다. 기존 샘플 담당자·업무 동작을 서버 공유 기능으로 오해하지 않도록 주의가 필요합니다.
- 전체 기능 구현 상태와 세부 순서는 `feature-implementation-status.md`, `feature-implementation-plan.md`, `remaining-implementation-plan.md`를 참고하세요.

## 다음 단계

다음 순서는 **3.4 — 업무 수정·상태 변경 저장소**입니다. 이후 삭제 저장소를 구현하고 서버 조회·쓰기를 업무 화면에 연결합니다.

## 검증 상태

2.1~2.20 DB 마이그레이션 적용·pgTAP 실행, 2.21~2.29 및 3.1~3.3 Vitest 실행은 확인되지 않았습니다. 앱 전체 빌드·브라우저·다중 계정 검증도 하지 않았으므로 어떤 테스트도 통과했다고 주장하지 않습니다. 기존 업무 화면은 계속 `localStorage` 기반이며 팀원 간 업무 공유는 완성되지 않았습니다.

외부 Supabase CLI/Docker 또는 프로젝트 환경, 브라우저 테스트가 필요한 검증은 실제 실행 전까지 확인된 사실로 표시하지 않습니다.
