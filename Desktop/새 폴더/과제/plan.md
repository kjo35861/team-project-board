# 자취생 생활비 분석 앱 — 계획설계서

## 1. 프로젝트 개요

- **한 줄 소개:** 자취생의 생활비 지출을 분석하는 앱
- **대상 사용자:** 대학생·자취생
- **핵심 목표:** 지출을 기록하고 소비 현황을 파악해 월 예산을 관리할 수 있도록 돕는다.

## 2. 핵심 기능

1. **지출 입력**
   - 지출 금액, 날짜, 카테고리, 메모를 입력한다.
   - 입력한 지출 내역을 저장하고 확인할 수 있다.

2. **카테고리별 분석**
   - 카테고리별 지출 금액과 전체 지출에서 차지하는 비율을 보여준다.
   - 월별 지출 내역을 확인할 수 있다.

3. **월 예산 초과 알림**
   - 사용자가 월 예산을 설정할 수 있다.
   - 지출이 예산을 초과하면 알림이나 안내를 표시한다.

## 3. 주요 사용자 흐름

1. 사용자가 월 예산을 설정한다.
2. 지출이 발생할 때마다 금액과 카테고리를 입력한다.
3. 앱에서 월간 총지출과 카테고리별 금액·비율을 확인한다.
4. 예산을 초과하면 안내를 확인하고 지출을 점검한다.

## 4. 데이터 항목

### 지출 내역

- 지출 ID
- 날짜
- 금액
- 카테고리
- 메모

### 월 예산

- 대상 연월
- 예산 금액

## 5. 화면 구성 초안

- **대시보드:** 이번 달 총지출, 예산 대비 사용 현황, 예산 초과 안내
- **지출 내역:** 지출 목록과 내역 추가 기능
- **분석:** 카테고리별 지출 금액 및 비율
- **예산 설정:** 월 예산 입력 및 수정

## 6. 완성 기준

- 사용자가 한 달간의 지출 내역을 입력하고 확인할 수 있다.
- 카테고리별 소비 금액과 전체 지출 대비 비율을 확인할 수 있다.
- 월 예산을 설정하고 수정할 수 있다.
- 지출이 설정한 월 예산을 초과하면 알아보기 쉬운 안내를 확인할 수 있다.

## 7. 개발 우선순위

### 1단계: 기본 기능

- 지출 내역 추가 및 조회
- 지출 카테고리 지정
- 월 예산 설정

### 2단계: 분석 기능

- 월별 총지출 계산
- 카테고리별 금액 및 비율 계산
- 예산 초과 여부 확인

### 3단계: 사용성 개선

- 지출 내역 수정 및 삭제
- 월별 내역 탐색
- 분석 결과를 이해하기 쉬운 형태로 표시
